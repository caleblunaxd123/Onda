# Referencias de diseño del propietario

Cuatro mockups de ONDA proporcionados el 2026-10-14. Son referencias de composición, marca y color,
no catálogos ni datos de producción. No inventar sus usuarios, cifras, salas, portadas o integraciones.
La corrección posterior exige tarjetas de salas horizontales y compactas; no elevarlas a grandes posters.
Las categorías Fotos/Archivos del mockup NO autorizan subidas: el propietario las retiró expresamente.
Navegación principal en vertical. Mantener contraste, accesibilidad y fuentes reales.
