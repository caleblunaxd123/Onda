# UX: claridad y referencia visual

Prioridad: entender en segundos «mira y escucha con amigos». Inicio muestra salas públicas reales con
tarjetas horizontales compactas (base 112 dp, poster aproximadamente 40 %), búsqueda, Mis salas y Crear sala.
La radio tiene su pestaña; el inicio no vuelve a reunir múltiples secciones de emisoras/moods/IA.
No hay participantes, popularidad o salas ficticias para aparentar actividad.

Crear sala elige fuente y privacidad; el nombre es opcional. Se entra automáticamente y se elige contenido
dentro. En YouTube Android se abre el navegador integrado, se elige Ver juntos/Añadir a la cola y se toca
un resultado. Buscar otro contenido no requiere crear otra sala. La web comunica su recorrido externo.

La sala mantiene el video primero, título y controles breves, personas/cola/invitación en paneles accesibles
y chat en tiempo real. Teclado colapsa el stage para dejar visible el composer; se respetan insets del gesto.
La orientación principal es vertical. El indicador refleja reproducción/pausa/desconexión; ±10 segundos
compartidos se muestran únicamente cuando el usuario puede controlar un video YouTube con duración.

Estética: identidad ONDA original, acentos cian/violeta moderados, contraste legible, alternativas claro/suave,
movimiento reducido y superficies consistentes entre inicio, acceso y creación. No se copiaron recursos Rave.
Las capturas del propietario sirven para jerarquía/flujo, no como código o datos de producción.

Chat acordado: texto, emojis, stickers incluidos por ID, respuestas, reacciones, edición, borrado y fijado.
Fotos, archivos y audios grabados están deshabilitados para controlar almacenamiento. Voz en vivo sigue
pendiente. La candidata agrega denuncia por mensaje, bloqueo en personas y lista de bloqueados en cuenta.
Una cita de alguien bloqueado no vuelve a mostrar su texto aunque el original esté fuera del historial cargado.

La cola ya admite votos y contenido fijado. Mejoras siguientes: pedir control sin interrumpir; eventos recurrentes y salas
favoritas; retomar una sesión con un solo toque. Primero medir abandono al crear/entrar y retorno semanal.
No cargar la pantalla principal con tarjetas premium o IA costosa antes de validar el uso.
