# Privacidad — borrador de desarrollo
Modo invitado: favoritos, historial, búsquedas, país y tema permanecen en almacenamiento local.
Borrar datos desde Ajustes. No hay cuenta ni sincronización en esta versión.
La API procesa filtros de catálogo; las conexiones del servidor/proxy pueden generar logs técnicos.
Escuchar conecta directamente al operador de la emisora, que recibe dirección IP y datos de conexión.
El mapa solicita tiles a su proveedor. No se solicita ubicación GPS.
No grabamos ni retransmitimos contenido; logos, nombres y emisiones pertenecen a sus titulares.
Pendiente revisión y datos del responsable antes de publicar comercialmente.
